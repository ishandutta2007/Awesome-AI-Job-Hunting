# AI-Job-Hunting: Cover Letters Directory

This directory contains the custom LaTeX document class, bundled open-source fonts, and tailored cover letters generated by the **AI-Job-Hunting** application engine.

## Directory Structure

- `cover.cls` — Custom LaTeX class defining the layout, typography, header styling, and contact block formatting.
- `OpenFonts/` — Bundled open-source typefaces (Lato and Raleway) providing elegant font styling without requiring system font installation.
- `cover_example.tex` — Baseline example cover letter illustrating the narrative structure and formatting hooks.
- `cover_<company>_<role>.tex` — Target-specific cover letters generated by `/apply`.

## LaTeX Compilation Guidelines

Cover letters MUST be compiled with **`xelatex`** due to fontspec requirements:

```bash
xelatex -interaction=nonstopmode cover_<company>_<role>.tex
```

## Tone & Narrative Philosophy in AI-Job-Hunting

1. **Direct Value Proposition**: Avoid generic throat-clearing openings like "I am writing to express my enthusiastic interest in...". Open with immediate relevance and proven impact.
2. **Forward-Looking Framing**: Connect past technical achievements directly to the target team's specific roadmap and challenges.
3. **Conversational Professionalism**: Clear, confident, jargon-free communication that sounds like a peer talking to a peer.
