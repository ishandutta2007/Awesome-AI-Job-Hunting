# AI-Job-Hunting: Curriculum Vitae (CV) Directory

This directory holds the LaTeX source files and compiled PDFs for your customized curriculum vitae generated by the **AI-Job-Hunting** framework.

## Structure & File Conventions

- `main_example.tex` — The reference/pristine baseline CV template using `moderncv` (banking style).
- `main_<company>_<role>.tex` — Role-tailored CV source created during the `/apply` workflow.
- `main_<company>_<role>.pdf` — Compiled PDF output.
- `main_<company>_<role>.txt` — Plaintext ATS extraction generated during the ATS compatibility review step.

## LaTeX Compilation Guidelines

The AI-Job-Hunting CVs are optimized for compilation with **`lualatex`**:

```bash
lualatex -interaction=nonstopmode main_<company>_<role>.tex
```

> **Why LuaLaTeX?** Modern MiKTeX and TeX Live installations can experience font expansion and fontawesome5 issues under `pdflatex`. `lualatex` provides robust UTF-8 and modern font handling out of the box.

## ATS Compliance & Design Standards

1. **Clean Typography**: Uses moderncv banking style with distinct section headings, bulleted accomplishments, and clear date alignments.
2. **Reverse Chronological Order**: Experience and education are listed starting with the most recent positions.
3. **No Unparseable Visual Hacks**: Avoid complex multi-column nested tables or floating text boxes that confuse Automated Tracking Systems (ATS).
4. **Action-Oriented Impact**: Every bullet point follows the structure *Action Verb + Context + Quantifiable Metric / Impact*.
